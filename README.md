# 🍽️ Confetti Cuisine

**Confetti Cuisine** é um projeto desenvolvido a partir do livro **_Get Programming with Node.js_**, com o objetivo de aprender e praticar os fundamentos do desenvolvimento web backend utilizando **Node.js**, **Express** e **MongoDB**.

O projeto simula uma plataforma simples de cursos culinários, explorando conceitos essenciais como rotas, controllers, models, middlewares, templates e persistência de dados.

---

## 📚 Objetivo do Projeto

Este projeto foi criado com foco educacional para:

- Compreender a arquitetura MVC no Node.js  
- Trabalhar com o framework Express e seus middlewares  
- Utilizar o MongoDB com Mongoose  
- Criar relacionamentos entre documentos  
- Renderizar páginas dinâmicas com EJS  
- Praticar organização e boas práticas no backend  

---

## 🧱 Tecnologias Utilizadas

- Node.js  
- Express  
- MongoDB  
- Mongoose  
- EJS (Embedded JavaScript Templates)  
- Express-Session  
- Bcrypt  
- Git / GitHub  

---

## 🧩 Funcionalidades

- Cadastro e autenticação de usuários  
- Gerenciamento de assinantes (Subscribers)  
- Associação entre usuários e assinantes  
- Listagem e visualização de cursos  
- Uso de virtuals no Mongoose  
- Middlewares para carregamento e tratamento de dados  
- Renderização de páginas dinâmicas com EJS  

---

## 🧠 Conceitos Trabalhados

- Diferença entre middleware e controller  
- Uso de hooks do Mongoose (`pre` e `post`)  
- Relacionamentos com `ObjectId` e `populate`  
- Separação de responsabilidades no backend  
- Fluxo de requisição e resposta no Express  
- Tratamento de erros assíncronos

## ⚠️ Observações

## 🎉 Conclusão

O **Confetti Cuisine** é um projeto prático para consolidar conceitos fundamentais do backend com Node.js, ajudando a entender como diferentes camadas da aplicação se conectam e colaboram entre si.
